# Подключение TikTok и Instagram

## Состояние обновления

Подключение аккаунтов отделено от добавления ролика. Поддерживаются несколько
подтверждённых каналов YouTube; при добавлении выбираются площадка и аккаунт,
после чего принимается одна ссылка. Если аккаунт один, его выбор пропускается.
В меню подключения есть Instagram и TikTok с явным уведомлением о недоступности.
Они не считаются подключёнными и не участвуют в начислениях до реализации OAuth
и провайдеров статистики. Старые аккаунты, ролики и баланс сохраняются.

## TikTok

1. Открыть https://developers.tiktok.com/ и зарегистрировать аккаунт разработчика.
2. Manage apps → создать приложение. Подключить Login Kit (Web) и Display API.
3. Запросить user.info.basic и video.list. Нужны согласование продуктов и доступов.
4. В настройках приложения получить Client key и Client secret.
5. Настроить HTTPS redirect URI после развёртывания обработчика авторизации.
6. Для проверки использовать разрешённые тестовые аккаунты; для остальных авторов
   пройти рассмотрение приложения. Подготовить сайт приложения, описание,
   политику конфиденциальности и условия согласно требованиям кабинета.

Документация: https://developers.tiktok.com/docs/en/display-api-get-started
Регистрация: https://developers.tiktok.com/docs/en/getting-started-create-an-app
Просмотры: /v2/video/query/ с полем view_count, токеном подключённого автора.

## Instagram

1. Открыть https://developers.facebook.com/apps/ и создать приложение с Instagram.
2. Выбрать Instagram API with Instagram Login, настроить вход профессиональных
   аккаунтов Business/Creator. Личные аккаунты для этой схемы не подходят.
3. В Instagram API setup получить Instagram App ID и Instagram App Secret.
4. Включить доступ к базовым данным и Insights, сверяя названия разрешений
   с текущей панелью Meta и документацией для выбранной схемы входа.
5. Добавить тестовый профессиональный аккаунт. Настроить HTTPS redirect URI
   после реализации обработчика авторизации. Для сторонних авторов пройти
   App Review и получить требуемый уровень доступа.

Документация: https://developers.facebook.com/docs/instagram-platform/
Официальная коллекция Meta: https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api

## Следующий этап разработки

Потребуются публичный HTTPS-адрес сервиса, OAuth callback endpoints,
одноразовый state с привязкой к Telegram ID, хранение токенов и их обновление,
получение аккаунтов и проверка принадлежности публикаций, плановый сбор просмотров,
обработка отзыва доступа, перенос метаданных площадки в отчёты и проверку выплат.
Нельзя заменить авторизацию каждого автора единственным общим API-ключом.
Конкретные redirect URI пока не реализованы: не регистрировать выдуманные адреса.
Секреты хранить в приватной конфигурации/ Railway Variables, не в Git.
