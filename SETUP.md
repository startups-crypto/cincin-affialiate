# Доступы и единый файл настроек

Скопируйте `config.example.toml` в `config.toml`. Заполните все нужные секции в этом одном файле. Заполненный файл исключён из Git; на сервер его передают отдельно. После изменения настроек бот нужно перезапустить.

## Telegram и владелец

1. Создайте бота в Telegram через @BotFather или используйте существующего.
2. Впишите его токен в `[telegram] → token`.
3. В `owner_ids` укажите числовой Telegram ID владельца, например `[123456789]`. Можно указать несколько владельцев через запятую. Никнейм с @ сюда не подходит. В работающем боте свой ID можно посмотреть командой `/id`.
4. Менеджер сначала запускает бота. Затем владелец назначает его в панели «Сотрудники». Менеджеров в файле перечислять не нужно: роли сохраняются в базе.

## YouTube

1. Откройте [Google Cloud Console](https://console.cloud.google.com/), создайте или выберите проект.
2. В **APIs & Services → Library** включите **YouTube Data API v3**.
3. В **Credentials → Create credentials → API key** создайте ключ.
4. Ограничьте ключ API **YouTube Data API v3**. Ограничение по IP можно добавить, когда известен адрес сервера.
5. Вставьте ключ в `[youtube] → api_key`.

Для чтения публичных просмотров авторам не нужно авторизовываться через Google. [Документация YouTube](https://developers.google.com/youtube/v3/getting-started).

## Google Sheets

1. В том же проекте Google Cloud включите **Google Sheets API**.
2. Откройте **IAM & Admin → Service Accounts → Create service account**. Имя может быть, например, `cincin-bot`. Роль владельца Google Cloud проекта ему не нужна.
3. Откройте созданный аккаунт → **Keys → Add key → Create new key → JSON**.
4. Из скачанного JSON скопируйте значения в секцию `[google_sheets.service_account]` файла `config.toml`: `project_id`, `private_key_id`, `client_email`, `client_id`, `private_key`. Остальные значения в шаблоне уже заполнены.
5. `private_key` можно скопировать из JSON вместе с двойными кавычками: последовательности `\n` преобразуются в переносы автоматически. Другой вариант — многострочная TOML-строка в тройных двойных кавычках. Не вставляйте весь JSON в поле `private_key`.
6. Создайте обычную пустую Google-таблицу. Нажмите **Поделиться**, добавьте email из `client_email` с правами **Редактор**. Доступ «всем по ссылке» не нужен.
7. Скопируйте ID таблицы — часть ссылки между `/d/` и `/edit` — в `[google_sheets] → spreadsheet_id`.

Бот сам создаёт вкладки «Обзор», «Выплаты», «Условия» и отдельные вкладки авторов. Сам файл Google-таблицы предварительно создаётся владельцем. Отдельный JSON-файл после переноса значений в `config.toml` для работы бота не требуется. [Документация сервисных аккаунтов Google](https://developers.google.com/workspace/guides/create-credentials).

## Партнёрская программа

Для запуска только просмотров и таблицы оставьте `[tracknow] → enabled = false`. Настройку переходов в @CinCinX_bot отложили до отдельного этапа.

Когда интеграция готова:

1. Установите `enabled = true`.
2. Укажите `api_key`, ID своей кампании в `campaign_id`, её название в `campaign_title` и адрес API в `base_url`.
3. В кампании должны быть правила: `CPA` с goal `card_issued` и комиссией 10 USD; `CPS` с goal `card_turnover` и комиссией 0.1 (0,1%). ID правил бот определяет сам.
4. Карточный сервис должен передавать в Tracknow события по партнёрской ссылке автора, включая все доступные карточные операции. Сам импорт комиссий в бот не подключает передачу этих событий.
5. Для получения начислений автор должен иметь отдельный привязанный `affiliateId`. Новый аккаунт создаётся по кнопке «Партнёрская ссылка»; существующий подключает владелец после проверки.

`configure_test_campaign.py` — вспомогательная команда, которая изменяет выбранную в конфигурации тестовую кампанию и её правила. Она не запускается автоматически. Не выполняйте её для действующей кампании без проверки настроек.

## Проверка и запуск

```sh
.venv/bin/python check_access.py
.venv/bin/python bot.py
```

Проверка подключений не меняет кампании и не создаёт пользователей. Тесты не требуют рабочих ключей:

```sh
.venv/bin/python -m unittest -v test_core test_partner test_links test_manager
```

В Git входят код, тесты, документация, изображение материала и шаблон настроек. Локальная база авторов, диалоги, кошельки, хэши выплат и ключи туда не входят. Для продолжения работы с уже зарегистрированными авторами перенесите отдельно папку `data/` вместе с приватным `config.toml`.

## Настройки текущего развёртывания

- ID владельца: `7241115648` (заполнен в шаблоне конфигурации).
- Токен Telegram-бота сохранён в закрытом секрете репозитория `TELEGRAM_BOT_TOKEN`.
- ID владельца также сохранён в секрете `OWNER_IDS`.

В истории Git токен отсутствует. Значения GitHub Secrets не попадают в Railway автоматически. Для текущей версии при запуске необходим заполненный `config.toml`; формирование конфигурации из секретов должно быть выполнено отдельно при развёртывании.

## Railway: конфигурация через Variables

Railway не получает файлы из GitHub Secrets автоматически. Для запуска без файла на диске добавьте в сервисе **Variables → New Variable**:

- Имя: `CONFIG_TOML`
- Значение: всё содержимое заполненного `config.toml`, включая секции и переносы строк. Не путь к файлу и не GitHub-ссылку.

Эта переменная имеет приоритет над локальным файлом. Отдельный JSON-ключ загружать не нужно: его поля уже входят в TOML. После сохранения примените изменения и выполните Redeploy.

Для текущей структуры репозитория Root Directory: `/`, Start Command: `python bot.py`. Значение переменной содержит ключи, поэтому не публикуйте его в Git или в логах.

## Два направления

В `[tracknow]` можно указать `exchange_campaign_id = 338` и `cards_campaign_id = 339`. Эти значения уже используются по умолчанию. Автор выбирает направление кнопкой; повторно создавать аккаунт для второго направления не нужно.

Рабочие цели кампаний: `card_open`, `card_top_up`, `card_withdrawal`, `chargeback`, `card_blocking`, `exchange`. Бот читает существующие правила, не изменяя их. Legacy `campaign_id` можно оставить для старой статистики либо установить в 0.

После переноса файлов в корень репозитория Root Directory в Railway должен быть пустым или `/`, Start Command — `python bot.py`.
